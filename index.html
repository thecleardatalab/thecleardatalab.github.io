Automated Clinic Analytics Pipeline

The problem
Reports were built by hand from six separate systems. Each took hours and the totals rarely matched.
What I built
One PostgreSQL warehouse fed nightly from all six sources, with 228 accuracy checks. If a check fails, yesterday's correct report stays live.
The result

Healthcare · Operations

Clinic Operations Dashboard

The question
When do patients actually come in, and are we staffed for it?
What the data showed
The busiest hour was 8pm, 25% busier than 9am. Sundays were 22% quieter than other days.
Why it matters
Shifts can move to match real demand: fewer idle hours in the morning, shorter queues at night.

Pharmacy Sales Dashboard

Yes. Your files are used only for your project, never shared or shown publicly, and deleted when the work is done if you ask. Happy to sign an NDA.

My data is very messy. Is that a problem?

No. Cleaning is part of every package. Most of the work in any good dashboard is making the data trustworthy first.

Do I need Power BI?

No. If you already use Excel or Google Sheets, I can build it there. Power BI is free for one person on Windows if you want to try it.

How do I pay?

Half to start, half on delivery. International clients can pay through Upwork or a bank transfer.

What if I don't like it?

Every package includes rounds of changes. We agree what the dashboard must answer before I start, so there are no surprises.
